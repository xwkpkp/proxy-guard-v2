============================================================
 Proxy Guard Agent v2.0.0 — Windows x64 快速开始
============================================================

对接公共代理池的防护型本地 HTTP 代理
Rust 数据面 · Go 控制面 · Python AI 层（可选）

------------------------------------------------------------
[1] 配置（可选）
------------------------------------------------------------
复制 config.example.yaml 为 config.yaml，按需修改。
默认监听 127.0.0.1:8888，无需改动即可启动。

------------------------------------------------------------
[2] 启动（两个终端窗口）
------------------------------------------------------------
终端 A（Rust 数据面，先启动）：

    .\proxy-guard-core.exe --listen 127.0.0.1:8888 --ctrl-port 8890 --rules rules

终端 B（Go 控制面）：

    .\guardctl.exe run -c config.yaml

（可选）终端 C — AI 研判层，需要 Python 3.10+：

    cd ai-py
    pip install -r requirements.txt
    python -m proxyguard_ai -c ..\config.yaml

------------------------------------------------------------
[3] 使用
------------------------------------------------------------
把浏览器 / 程序的 HTTP 代理设置为：127.0.0.1:8888

管理接口（调试）：
    http://127.0.0.1:8891/api/stats     — 运行统计
    http://127.0.0.1:8890/health        — 数据面健康检查

------------------------------------------------------------
[!] 安全须知
------------------------------------------------------------
- 仅用于低风险、匿名读取、可失败可丢弃的场景。
- 公共代理默认不可信：不要用来登录重要账号、传密码 / Token /
  支付信息（数据红线会拦截，但别依赖）。
- 本包为 Windows x86_64 构建：
    proxy-guard-core.exe — Rust 1.99（GNU 工具链，静态链接）
    guardctl.exe         — Go 1.23（CGO 关闭，stripped）
- 完整文档 / 构建指南 / 路线图：见 README.md
